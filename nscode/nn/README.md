# nn — GPU 卷积神经网络识别 MNIST 手写数字

用纯 Nano Script 编写并在 GPU 上训练的卷积神经网络，识别 28×28 灰度图中的 0–9。
前向传播、反向传播、梯度归约和 Adam 优化器都是普通的 ns 函数：
同一份源码由 `shader` 模块转译为 MSL / GLSL / HLSL / WGSL 计算着色器在 GPU 上运行，
整个项目不使用机器学习框架，也没有手写着色器文件。

nn 只在有 GPU 的设备上运行：训练、评估、窗口推理和 3D 视图都需要 GPU，
没有 CPU 训练或推理模式，没有 GPU 时直接报错退出。
同一批计算核也可以在 CPU 上逐个 invocation 执行，但这只用作单元测试和
`--gpu-check` / `--benchmark` 的参考实现，不是可用的运行方式。

## 运行

在仓库根目录执行一次数据下载，然后训练：

```sh
python3 nscode/nn/scripts/download_mnist.py
ns run nscode/nn --train
ns run nscode/nn
```

`--train` 在 GPU 上训练 10 轮，每轮使用全部 60,000 张训练图，每轮结束后评估全部
10,000 张测试图，并保存检查点到 `nscode/nn/bin/mnist/model-cnn.nn`，下次 `ns build` 会把它打包进应用。
不带参数的 `ns run nscode/nn` 打开窗口，加载该检查点并以 3D 展示模型结构。

| 命令 | 作用 |
| --- | --- |
| `ns run nscode/nn --train [1..10]` | GPU 训练 CNN，可指定轮数，从初始权重开始 |
| `ns run nscode/nn --evaluate` | 加载 CNN 检查点，在 GPU 上评估全部测试图；低于 99% 断言失败 |
| `ns run nscode/nn --gpu-check` | 用同一批数据分别在 CPU 和 GPU 上执行全部计算核，比对激活、梯度和 Adam 结果 |
| `ns run nscode/nn --benchmark` | 10 个 64 张图的训练批次：CPU 参考实现 vs GPU |
| `ns run nscode/nn --emit-shaders` | 把 10 个计算核的四种着色语言输出写到 `bin/shaders/` |

清单使用 `target = "exec"`，`ns run` 构建原生代码后启动。
`ns build nscode/nn` 打包原生应用，只包含已有的检查点（约 1.4 MB），不含 MNIST 数据。

## 结果

本机实测（Apple Silicon，Metal），固定种子，可复现：

| 参数 | 训练 | 独立测试集准确率 |
| --- | --- | --- |
| 56,714 | GPU 10 轮，68.6 秒（含每轮测试评估） | **99.29%**（9929/10000） |

第 4 轮达到 99.00%。

逐轮测试准确率：97.99%、98.72%、98.89%、99.00%、99.11%、99.25%、99.23%、99.28%、99.27%、99.29%。

逐步改进的记录（同一训练代码、固定种子）：

| 配置 | 测试准确率 |
| --- | --- |
| 8/16 通道、平均池化、无增强，8 轮 | 98.45% |
| 16/32 通道、最大池化、±2 像素平移增强、学习率指数衰减，10 轮 | 99.03% |
| 再加 64 单元 ReLU 隐藏层（当前） | 99.29% |

`--gpu-check` 的 CPU/GPU 最大绝对误差（×1e-6）：激活 0.83、概率 0.09、
参数梯度 0.31、激活梯度 0.09；一次 Adam 更新后权重 0.01、动量 0.03。

`--benchmark`：10 个批次，CPU 参考实现原生执行同一批计算核 33,269 ms，GPU 87 ms，约 **384 倍**。
计时包含主机端派发、批次上传和最终 GPU 同步，不含着色器编译和 IDX 解码。
耗时随机器变化。

## 网络

```text
28×28×1 ─conv3×3─▶ 26×26×16 ─ReLU─▶ maxpool2 ─▶ 13×13×16
        ─conv3×3─▶ 11×11×32 ─ReLU─▶ maxpool2 ─▶ 5×5×32 = 800
        ─dense─▶ 64 ─ReLU─▶ dense ─▶ 10 ─softmax─▶ 交叉熵
```

- 卷积为 valid 填充；11×11 池化时舍弃最后一行一列。
- 通道数和隐藏层宽度是 `src/cnn_kernels.ns` 顶部的 `lit`，全部偏移由它们推出。
- 小批量 64，Adam（β1 = 0.9，β2 = 0.999），学习率 `0.0015 × 0.7^轮次`。
- 训练图每张随机平移 −2…2 像素（越界补 0），种子由已训练样本数决定；测试图不变换。
- 权重用固定种子 He 均匀分布初始化，偏置为 0；每轮按轮次确定性洗牌。

## GPU 实现

`src/cnn_kernels.ns` 中的 10 个 `cs_cnn_*` 函数就是全部计算：

| 计算核 | 网格 | 作用 |
| --- | --- | --- |
| `cs_cnn_conv` | 输出元素 × 样本 | 3×3 卷积 + 偏置 + ReLU |
| `cs_cnn_pool` | 输出元素 × 样本 | 2×2 最大池化 |
| `cs_cnn_dense` | 输出 × 样本 | 全连接投影，可选 ReLU |
| `cs_cnn_softmax` | 样本 | 数值稳定 Softmax、预测类别、交叉熵对 logits 的导数 |
| `cs_cnn_dense_backward` | 输入 × 样本 | 全连接层输入梯度，乘 ReLU 掩码 |
| `cs_cnn_dense_gradient` | 权重 + 偏置 | 全连接权重和偏置梯度，在批次上归约 |
| `cs_cnn_pool_backward` | 输入元素 × 样本 | 池化反向：梯度只传给窗口内第一个最大值，乘 ReLU 掩码 |
| `cs_cnn_conv_backward` | 输入元素 × 样本 | 卷积输入梯度（转置卷积） |
| `cs_cnn_conv_gradient` | 权重 + 偏置 | 卷积权重和偏置梯度，在批次和空间上归约 |
| `cs_cnn_adam` | 56,714 | 带偏差修正的 Adam 更新 |

每个参数梯度由一个线程独立求和，没有原子操作，结果是确定的。
数据放在 7 个 `GPU_MEM_DEVICE` 存储槽中：参数、批次像素与标签、激活、激活梯度、
参数梯度、概率与预测、Adam 一阶和二阶动量。计算核通过 `shader_buffer_f32` /
`shader_buffer_store_f32` 读写这些槽，层尺寸和偏移经 root 常量传入，
所以两层卷积、两层全连接分别共用同一组计算核。

一个训练批次是 CPU 端的一次像素上传加 17 次派发（前向 7、反向 9、Adam 1）；权重、动量和激活
始终驻留在 GPU 上，只在评估或保存时读回概率或参数。
`src/cnn_engine.ns` 的 `cnn_launch` 在 GPU 上派发，在 CPU 上用 `shader_host_buffer`
绑定同样的数组后逐个 invocation 调用同一函数，这就是 `--gpu-check` 和单元测试的依据。

目前仅在 macOS 的 Metal 后端实际运行验证；GLSL / HLSL / WGSL 输出经转译测试，
未在 Vulkan / DirectX 12 设备上运行。

## 窗口

窗口只用来展示模型结构，不读取 MNIST 数据，也不训练或评估；训练和评估都在命令行完成。
启动时加载 `model-cnn.nn` 检查点，找不到则显示固定种子的初始权重。
界面沿用 ns_lens 的黑白灰配色：3D 视图铺满窗口，顶栏、状态栏和层列表半透明地浮在上面。

- **3D 视图**：19,050 个神经元各是一个倒角立方体，七层从左到右排列；每层的特征图
  拼成一面墙（16 通道 4×4、32 通道 8×4），全连接层和输出层用更大的立方体。
  层的输出尺寸标签跟随相机，交替放在墙的上方和下方。
- **灰度**：有参数的层取流入该神经元的 |权重| 之和（含偏置）；输入层和池化层没有参数，
  取读取它的下一层 |权重| 之和；每层按自身最大值归一化。因此卷积层每个通道是一种灰度，
  输入层和池化层能看出卷积核覆盖不到的边缘更暗。
- **层列表**：左侧列出每层的类型、输出尺寸和参数量；鼠标悬停某一行时，该层在 3D 中提亮，
  其余层变暗。
- **操作**：左键拖动旋转，右键拖动平移，滚轮或触控板捏合缩放；顶栏 **Reset view** 恢复默认视角。
- **状态栏**：显示加载的检查点路径和训练轮数。

全部立方体由一次 `gpu_draw_vertices(0, 132, 19050)` 实例化绘制：网格只有一个
132 顶点的倒角立方体，顶点着色器用 `shader_instance_id()` 推出该实例所在的层、通道和位置，
不需要逐实例的位置缓冲。灰度由两个 ns 计算核（`cs_cnn_view`、`cs_cnn_view_scale`）
直接读取 GPU 上的参数计算，再交给顶点着色器，CPU 不回读任何数据。
立方体在 ui 之前的深度屏幕通道中绘制，ui 叠加在上面。

## 数据和模型

数据来源：[CVDF 的 MNIST 镜像](https://github.com/cvdfoundation/mnist)。
下载器使用其 Google Cloud Storage 地址，逐文件验证原始压缩文件的 MD5 和解压后长度，
再原子写入 `bin/mnist/`。运行时另行校验 IDX 魔数、数量、28×28 尺寸和 0–9 标签。
训练集和测试集始终独立，像素除以 255 归一化到 `[0,1]`。

下载数据、可执行文件和训练模型都在被忽略的 `bin/` 下，不纳入源码。
`ns clean nscode/nn` 会删除它们，之后需要重新下载和训练。
`NS_MNIST_DIR` 可指定其他数据目录，命令行模型也在该目录读写。
应用包运行前会切换到自己的资源目录，所以程序先按环境变量 `PWD`（`ns run` 的启动目录）
查找 `bin/mnist` 或 `nscode/nn/bin/mnist`，找不到才用包内的只读副本；
这样命令行训练的模型写回项目，不会写进下次构建就被覆盖的应用包。

CNN 检查点 `model-cnn.nn`（格式版本 2，1,361,168 字节）带魔数、版本、参数量、批次和训练进度，
随后是参数和两组 Adam 动量，每个数以 1e-12 定点的 64 位整数保存，从中断处继续训练
时 Adam 状态完整。加载时先校验整个文件（尺寸、范围、二阶动量非负），再替换参数；
保存采用原子写入。

## 源码

- `src/cnn_kernels.ns`：张量布局常量和 10 个计算核。
- `src/cnn_engine.ns`：GPU 内存和着色器创建、CPU/GPU 双路派发、前向 / 反向 / Adam 编排、同步与读回。
- `src/cnn_cli.ns`：GPU 校验、基准、检查点、评估和命令行训练。
- `src/cnn_export.ns`：导出转译后的着色器源码。
- `src/common.ns`：`exp` / `log` / 随机数等辅助函数。
- `src/mnist.ns`：IDX 校验、归一化、确定性洗牌，以及数据和检查点的目录查找。
- `src/cnn_view.ns`：3D 架构视图：倒角立方体网格、实例布局、灰度计算核、顶点 / 片元着色器、层高亮、轨道相机。
- `src/main.ns`：命令行入口，以及只展示模型结构的窗口（顶栏、层列表、状态栏）。

## 测试

```sh
ns test nscode/nn
ns test --cpu nscode/nn
ns lint nscode/nn
ns lint nscode/nn/test
ns run nscode/nn --gpu-check
```

单元测试不依赖下载的数据和 GPU：在 CPU 上执行 CNN 计算核，用有限差分校验两层卷积、
两层全连接的权重和偏置梯度（含最大池化路由），校验 Softmax 归一化、检查点数值编码，以及计算核向
四种着色语言的转译；3D 视图测试校验倒角立方体网格（法线、朝外的绕序）、实例布局、灰度在 CPU 上的计算和每层归一化；
另覆盖 `exp` / `log` / 随机数辅助函数、IDX 校验和洗牌。
完整 MNIST 上的结果和 GPU 一致性由 `--train`、`--evaluate`、`--gpu-check` 验证。
