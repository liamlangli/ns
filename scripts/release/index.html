ns

a small, explicitly typed, data-oriented functional language.

macos / linux

curl -fsSL https://liamlangli.com/ns/install.sh | sh

windows powershell

irm https://liamlangli.com/ns/install.ps1 | iex

windows cmd

curl -fsSLO https://liamlangli.com/ns/install.bat && install.bat

then

ns create hello
cd hello
ns run

installs into ~/.ns and adds ~/.ns/bin to PATH.

prebuilt for macos arm64 (14+), linux x86_64 and windows x86_64; other hosts build from source.

remove with: rm -rf ~/.ns
